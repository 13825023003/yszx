使用说明

本原型用于交互与视觉评审，所有数据均为前端模拟

🧪

静态交互原型

基于原生 HTML / CSS / JS，无需安装依赖或启动服务端，直接双击本页面即可浏览。表单提交、导入导出、图表与弹窗均为前端模拟。

💾

数据持久化

操作数据保存在浏览器 localStorage 中（ys_ 前缀），刷新页面不会丢失；清除站点数据即可恢复初始演示数据。
