## 2. 产品定位与目标

### 2.1 一句话定位

面向互联网学员的**免费**学习平台：按学习路线学 B 站课程，按阶段刷题验证，用 AI 面试检验掌握程度并给出报告。

### 2.2 目标用户

**C 端学员**

| 画像 | 核心诉求 | 典型场景 |
|---|---|---|
| 转行求职者 | 需要清晰路径 + 能力证明 | 选方向 → 按阶段学习 → 刷题 → AI 面试 → 报告 |
| 在职提升者 | 碎片时间高效补短板 | 直接进入某阶段刷题 / 发起面试摸底 |
| 在校学生 | 免费刷题、通过考核 | 以刷题为主，路线为辅 |

**B 端机构运营**

| 角色 | 核心诉求 |
|---|---|
| 内容运营 | 不改代码就能组织路线、课程、题库 |
| 运营负责人（只读） | 看学员进展、内容效果，不误改内容 |
| 超级管理员 | 账号、角色、权限与审计 |

### 2.3 核心业务目标

1. **可发现**：未登录即可浏览学习路线，作为获客落地页。
2. **可推进**：阶段有明确达标门槛，学员知道"自己学到哪、还差什么"。
3. **可验证**：刷题 + AI 面试共同构成"能力证明"，不只是内容浏览。
4. **可运营**：运营可独立完成"上新一条路线 + 配套题库"。
5. **可度量**：后台 5 项核心指标持续反映内容质量与学员流失点。

### 2.4 成功指标（一期看板口径）

注册数、日活/新增学员、路线完成率、阶段达标率、面试完成率与通过率。

## 4. 范围界定

### 4.1 一期（MVP）

- C 端：注册登录、首页、学习路线、阶段、课程（跳 B 站 + 标记已学完）、逐题练习、错题本、AI 面试（题库问答、文字为主语音可选）、面试报告、学习记录、面试记录、个人中心。
- B 端：三角色账号体系、学科/阶段、B 站课程库、刷题题库、面试题库、学习路线管理、学员管理（查看/禁用/手动解锁）、操作日志、5 指标看板。
- 内容上线：草稿 → 发布两态。

### 4.2 二期（不在本期验收范围）

- 题库/课程的 Excel 批量导入
- 面试报告分享、路线综合面试（一条路线一场）
- 看板下钻到个人、时间/学科多维筛选
- 简答与面试评分的申诉/人工复核
- 内容失效链接检测与提醒

### 4.3 明确不做

- 支付、会员、课程售卖、多机构租户
- 社区、评论、私信、排行榜
- 学习证书、积分体系
- 独立 App（一期按 Web 适配，是否做小程序另行评估）

## 5. 核心概念与业务规则

### 5.1 术语

| 术语 | 定义 |
|---|---|
| 学科 Subject | 内容的最高归类，如"Java 开发""Agent 开发""AI 全栈开发" |
| 阶段 Stage | 学科下的有序单元，是**学习与刷题的共同单位** |
| 课程 Course | 阶段下的一节 B 站视频，点击跳转 B 站 |
| 题目 Question | 阶段下的练习题，题型为判断/单选/多选/简答 |
| 面试题 InterviewQuestion | 阶段下的 AI 面试题，含评分维度与参考答案 |
| 学习路线 Route | **阶段的有序引用**，可跨学科；本身不是新的阶段模型 |
| 阶段达标 | 解锁下一阶段的门槛，见 BR-05 |
| 手动解锁 | 运营在后台为单个学员开放某个阶段入口，见 BR-13 |

### 5.2 业务规则（基线，编号供开发与验收引用）

**BR-01 内容状态与可见性**
所有内容（课程、题目、面试题、路线、阶段、学科）均为"草稿/发布"两态。C 端仅可见发布态内容。内容下架后，新学员不可见；老学员的历史记录与已获进度保留（见 BR-14）。

**BR-02 路线结构**
- 学习路线引用若干阶段并排序，可跨学科。
- 同一条路线内，同一阶段不重复出现。
- 一个课程只归属一个学科下的一个阶段；复用于多条路线通过路线引用阶段自然实现。
- 学员可同时学习多条路线，不锁定路线。

**BR-03 选学与解锁**
- 学员首次进入某学习路线的阶段页面，即视为"选学该路线"。
- 路线内第 1 个阶段默认解锁；第 i 个阶段的解锁条件为：**该路线内第 i-1 阶段已达标**。
- 若同一阶段被多条学员已选学路线覆盖，**任一前序达标即可解锁**。
- 管理员手动解锁可绕过上述条件，但**不计为已完成**（见 BR-13）。

**BR-04 学习进度**
- 学员在课程详情页手动"标记已学完"，该动作计入学习进度。
- 标记可取消（取消后若已满足阶段完成条件，需重新判定，见待定项 T-03）。

**BR-05 阶段达标**
阶段达标必须同时满足：
1. 该阶段**全部已发布题目**均有作答记录；
2. 该阶段**平均单题得分率 ≥ 60%**。

**BR-06 得分率口径**
- 单题得分率：客观题答对 = 100%，答错 = 0%；简答题 = 大模型评分（0–100）/ 100。
- **每题取历史最高得分率**参与阶段平均。
- 不限次数重做，重做不重置历史最高分。
- 阶段一旦达标，状态锁定；后续新增题目不使已达标学员降级（待定项 T-01）。

**BR-07 刷题模式**
- 一期唯一模式：逐题练习。
- 按阶段进入，按顺序逐题作答；**未做过的题优先**。
- 提交即判定并展示解析；学员可随时退出，下次从中断处继续。
- 判断题、单选题、多选题为客观判定；多选题漏选/错选均判错（待定项 T-02）。

**BR-08 简答题判分**
- 由大模型对照后台维护的"参考答案 + 得分要点"评分，给出分数与简短点评。
- **同权计入阶段达标**。
- 判分失败或超时：该次作答不计入统计，允许重试（见待定项 T-04）。

**BR-09 错题本**
- 错题本为**动态视图**：当前最高得分率未达阈值的题自动出现，达标后自动消失。
- 学员可手动移除个别题；手动移除不影响达标计算。
- 判定阈值：客观题答错即收录；简答题得分 < 60 收录（待定项 T-05）。
- 支持按学科/阶段筛选。

**BR-10 面试发起与规模**
- 按"学科 + 阶段"发起；**仅已解锁阶段可发起**，不强制要求该阶段已达标。
- 每场固定抽 **5 题**，不限总时长、每题不限时。
- 中途退出：本场作废，不生成报告。
- 同一场次内题目不重复；阶段面试题库 ≥ 5 题方可发布（见 BR-15）。

**BR-11 面试作答与报告**
- 作答方式：文字输入为主，语音作答为可选项（语音转写后进入同一评分链路）。
- 逐题提交，提交后不可修改。
- 报告包含：总分、分维度评分、通过/不通过结论、逐题点评与参考答案。
- **通过标准：总分 ≥ 80 且 每个维度 ≥ 60**（阈值后台可配）。
- 总分 = 5 题题目得分的平均值；维度分 = 该维度在各题得分的平均值（详见 T-06）。

**BR-12 面试次数**
不限次数。同一阶段可反复面试，历次报告全部保留。

**BR-13 手动解锁**
- 运营可在学员详情页对单个学员手动解锁指定阶段。
- 手动解锁只开放入口，**不计为已达标**，不影响进度百分比与看板统计。
- 必须记录操作日志（操作人、学员、阶段、时间）。

**BR-14 内容下架影响**
内容下架后：新学员不可见；老学员的历史学习记录、答题记录、面试记录、已获达标状态全部保留。

**BR-15 发布校验**
- 阶段发布前校验：刷题题目 ≥ 10 道。
- 面试题库发布前校验：该阶段面试题 ≥ 5 道。
- 学习路线发布前校验：所选阶段均已发布。

**BR-16 账号**
- 学员：手机号 + 短信验证码注册/登录；未登录可浏览路线，进入刷题/面试/记录时引导登录。
- 后台账号与学员账号相互独立，不互通。

## 7. 功能需求

### 7.1 C 端

#### 7.1.1 首页
- 展示各学习路线入口与平台价值说明。
- 未登录：显示登录/注册入口；已登录：显示"继续学习"（最近进入的阶段与进度）。
- 空内容时展示占位空态。

#### 7.1.2 学习路线列表 / 路线详情
- 列表：路线名称、简介、阶段数、预计周期；仅展示已发布路线。
- 详情：路线简介、阶段列表（阶段名、课程数、题量、面试入口）。
- 未登录：隐藏进度与解锁状态；已登录：显示每个阶段的状态（未解锁 / 学习中 / 已达标）。

#### 7.1.3 阶段详情
- 内容：阶段简介、课程列表、刷题入口、面试入口。
- 状态：未解锁（入口置灰 + 提示完成上一阶段）；已解锁未达标；已达标。
- 未登录点击刷题/面试 → 引导登录。

#### 7.1.4 课程详情
- 内容：课程名称、简介、所属阶段、B 站跳转按钮、"标记已学完"。
- 未登录：仅可跳转 B 站。
- 已学完：可取消标记（见 T-03）。

#### 7.1.5 登录 / 注册
- 手机号 + 验证码；验证码 60 秒重发限制，按手机号/IP 限频。
- 需展示用户协议与隐私政策入口。

#### 7.1.6 我的学习
- 当前选学的路线与进度（已完成阶段数 / 阶段总数）。
- 阶段完成明细：已学完课程数、刷题正确率、达标状态。
- 最近学习记录。

#### 7.1.7 刷题中心
- 按学科 → 阶段聚合，展示每个已解锁阶段的做题进度与正确率。
- 未解锁阶段显示但不可进入。

#### 7.1.8 答题页（核心）
- 单题展示，题型适配（判断/单选/多选/简答）。
- 提交后即时判定：客观题显示对错与解析；简答题显示分数、点评与参考答案。
- 未做题优先；断点续做。
- 阶段全部题目答完时展示完成态：正确率、错题数、是否达标、解锁了哪一阶段、去面试入口。
- 简答题判分中/失败的可重试态。

#### 7.1.9 错题本
- 当前未达标题目的动态列表，按学科/阶段筛选。
- 支持"重做"与"手动移除"。

#### 7.1.10 面试中心
- 列出已解锁阶段的面试入口；展示历次最高分与通过状态。

#### 7.1.11 面试进行页（核心）
- 第 N/5 题、题干、文字输入框、语音作答按钮（可选）。
- 状态：录音中、转写中、提交中、网络失败重试。
- 退出需二次确认，提示"本场将作废"。

#### 7.1.12 面试报告
- 总分、分维度评分、通过/不通过结论、逐题点评与参考答案。
- 生成中、生成失败可重试。
- 可"再面一次"。

#### 7.1.13 面试记录
- 历次面试列表：阶段、时间、总分、结论；可查看报告。

#### 7.1.14 个人中心
- 手机号、昵称、学习统计（学习阶段数、刷题数、面试次数）。
- 退出登录、账号注销（见 T-07）。

### 7.2 B 端

#### 7.2.1 后台登录
- 账号密码登录；仅超级管理员可创建后台账号。

#### 7.2.2 工作台
- 今日新增/活跃、待处理提醒（如某阶段题量不足、内容长期草稿）。

#### 7.2.3 数据看板
- 5 项指标：注册数、日活/新增、路线完成率、阶段达标率、面试完成率与通过率。
- 统计周期与下钻能力见 T-08。

#### 7.2.4 学科管理
- 列表、新增、编辑、排序、启用/停用。

#### 7.2.5 阶段管理
- 学科下的阶段列表、排序、发布。
- 展示每阶段题量与面试题量，未达 BR-15 下限时禁止发布并提示。

#### 7.2.6 B 站课程库
- 列表（按学科/阶段/状态筛选）、新增、编辑、发布/下架。
- 字段：课程名、所属阶段、B 站链接、封面、简介、排序。
- 批量导入为二期。

#### 7.2.7 刷题题库
- 列表（按学科/阶段/题型/状态筛选）。
- 新增/编辑：题型、题干、选项、正确答案、解析；简答题额外维护参考答案与得分要点。
- 发布/下架；批量导入为二期。

#### 7.2.8 面试题库
- 列表（按学科/阶段/状态筛选）。
- 新增/编辑：题干、参考答案、评分维度定义、维度权重（默认等权）。
- 发布/下架；每阶段 ≥ 5 题才可发布。

#### 7.2.9 学习路线管理
- 路线基本信息 + 跨学科挑选阶段 + 拖拽排序。
- 发布/下架；发布前校验所选阶段均已发布。

#### 7.2.10 学员列表
- 手机号、注册时间、选学路线、当前阶段、状态、最近活跃。
- 筛选：状态、注册时间、学科/路线。

#### 7.2.11 学员详情
- 三段只读：学习记录（课程完成、阶段达标）、答题记录、面试记录与报告。
- 操作：禁用/启用账号、手动解锁指定阶段（记录操作日志）。

#### 7.2.12 操作日志
- 记录：登录、内容发布/下架、学员禁用/启用、手动解锁、后台账号变更。
- 字段：操作人、角色、对象、动作、时间、结果；支持筛选。

#### 7.2.13 系统用户 / 角色 / 我的账号
- 用户：新增、编辑、禁用、重置密码、分配角色。
- 角色：三种固定角色的权限项展示（只读）。
- 我的账号：修改密码。

## 8. 关键流程

### 8.1 注册 → 选路线 → 学习
游客浏览首页/路线 → 进入阶段详情 → 点击刷题或面试 → 引导登录 → 手机号验证码登录 → 返回原阶段 → 自动记为"选学该路线" → 首个阶段解锁。

### 8.2 学习 → 刷题 → 达标 → 解锁
阶段详情 → 课程详情 → 跳转 B 站观看 → 返回标记已学完 → 进入答题页逐题作答 → 阶段题目全部作答且平均得分率 ≥ 60% → 完成态显示达标 → 解锁下一阶段 → 提示可发起本阶段 AI 面试。

### 8.3 AI 面试 → 报告
面试中心选阶段 → 抽 5 题 → 逐题作答（文字/语音）→ 交卷 → 报告生成中 → 生成成功：总分、维度、结论、逐题点评；生成失败可重试 → 记录进入面试记录。

### 8.4 运营上新一条路线
新建学科（如需）→ 建阶段 → 录课程（B 站链接）→ 录刷题题目（≥ 10）→ 录面试题（≥ 5）→ 发布阶段 → 新建路线 → 跨学科拖入阶段并排序 → 发布路线 → C 端可见。

### 8.5 学员卡住的处理
学员反馈无法进入下一阶段 → 运营在学员详情查看答题记录 → 若为评分异常或特殊学员，手动解锁下一阶段 → 记录操作日志 → 该阶段不计为已完成。

## 9. 数据模型（概念层）

| 实体 | 关键属性 | 关系 |
|---|---|---|
| Subject 学科 | 名称、排序、状态 | 1:N Stage |
| Stage 阶段 | 所属学科、名称、排序、状态 | 1:N Course / Question / InterviewQuestion |
| Course 课程 | 所属阶段、名称、B 站链接、封面、排序、状态 | N:1 Stage |
| Question 题目 | 所属阶段、题型、题干、选项、答案、解析、参考答案与要点、状态 | N:1 Stage |
| Route 学习路线 | 名称、简介、状态 | M:N Stage（有序，RouteStage 排序） |
| InterviewQuestion 面试题 | 所属阶段、题干、参考答案、评分维度、权重、状态 | N:1 Stage |
| Student 学员 | 手机号、昵称、状态、注册时间 | 1:N 各类记录 |
| CourseProgress 课程进度 | 学员、课程、是否已学完、时间 | N:1 Student/Course |
| AnswerRecord 答题记录 | 学员、题目、作答内容、得分、得分率、来源（练习/重做）、时间 | 每次作答一条 |
| StageProgress 阶段进度 | 学员、阶段、是否达标、达标时间、是否手动解锁 | 学员-阶段唯一 |
| WrongBookRemoval 错题移除 | 学员、题目、时间 | 动态错题本的白名单 |
| InterviewSession 面试场次 | 学员、阶段、状态、开始/结束时间 | 1:N InterviewAnswer |
| InterviewAnswer 面试作答 | 场次、题目、作答内容、题目得分、维度得分 | N:1 Session |
| InterviewReport 面试报告 | 场次、总分、维度分、结论、逐题点评 | 1:1 Session |
| AdminUser / Role | 账号、角色、状态 | — |
| OperationLog 操作日志 | 操作人、对象、动作、时间、结果 | — |

> 阶段完成状态按"学员-阶段"唯一存储；解锁状态由所属路线的前序阶段实时判定（规则见 BR-03）。

## 13. 风险清单
